# Схема подключения

## Luckfox Aura — распиновка для данного проекта

| Пин Aura | Сигнал       | Подключение                    |
|----------|--------------|--------------------------------|
| MIPI0    | CSI-2 Lane0  | Фронтальная камера (IMX335)    |
| MIPI1    | CSI-2 Lane1  | Кабинная камера (OV4689)       |
| ETH      | GbE          | Роутер / сервер                |
| UART2_TX | RS-485 TX    | Светофорный контроллер         |
| UART2_RX | RS-485 RX    | Светофорный контроллер         |
| GPIO0    | Вход, pull-up | Внешний триггер (датчик авто) |
| GPIO1    | Выход        | Управление IR подсветкой       |
| USB3     | USB-A        | Отладка / ПК                   |
| 5V IN    | VCC          | DC-DC (12 В → 5 В, 3 А)       |
| GND      | GND          | Общий провод                   |

## Фронтальная камера (IMX335, MIPI CSI-2)

```
IMX335 module          Luckfox Aura
───────────────────    ────────────
CLK+  ─────────────────► MIPI0_CLK+
CLK-  ─────────────────► MIPI0_CLK-
D0+   ─────────────────► MIPI0_D0+
D0-   ─────────────────► MIPI0_D0-
D1+   ─────────────────► MIPI0_D1+
D1-   ─────────────────► MIPI0_D1-
SCL   ──── 4.7 kΩ ──── I2C0_SCL (3.3 V)
SDA   ──── 4.7 kΩ ──── I2C0_SDA
PWDN  ─────────────────► GPIO2 (active-low)
RESET ─────────────────► GPIO3 (active-low)
VDD   ─────────────────► 3.3 V
GND   ─────────────────► GND
```

## Кабинная камера (OV4689, MIPI CSI-2)

Аналогично, на MIPI1 / I2C1.

## IR подсветка (850 нм, 30 Вт)

```
GPIO1 ──► MOSFET gate (IRLZ44N)
MOSFET drain ──► IR LED array (12 В, 2.5 А)
MOSFET source ──► GND
12 V ──► IR LED array (+)
```

Управление: GPIO1 HIGH = IR включена; ШИМ для регулировки яркости.

## Светофорный контроллер (RS-485, UART2)

```
RV1126B UART2_TX ──► MAX485 DE/RE + DI ──► RS-485 A/B ──► Светофор
RV1126B UART2_RX ──◄ MAX485 RO          ──◄ RS-485 A/B ──◄ Светофор
```

Протокол: 9600 baud, 8N1.
Команды: `RED\r\n`, `GREEN\r\n`, `YELLOW\r\n` (зависит от производителя контроллера).

## Питание

```
12 В DC (от сети или PoE++) ──► DC-DC LM2596 (12 В → 5 В, 3 А)
                                      │
                                 Luckfox Aura 5 V IN
                                      │
                                 (Aura выдаёт 3.3 В для камер)
```

Потребление при нагрузке:

| Режим              | Ток 12 В | Мощность |
|--------------------|----------|----------|
| Idle               | ~0.3 А   | ~3.6 Вт  |
| Инференс + 2 камеры| ~0.8 А   | ~9.6 Вт  |
| + IR подсветка 30 Вт| ~3.3 А  | ~39.6 Вт |
