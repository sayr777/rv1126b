# Архитектура системы

## Назначение

Стационарная IP-камера интеллектуального контроля нарушений ПДД на перекрёстках.
Четыре функции на одном устройстве без подключения к серверу для инференса:

| Функция | Нарушение | Статья КоАП РФ |
|---------|-----------|---------------|
| LPR (License Plate Recognition) | Идентификация ТС по номеру | — |
| Вафельная разметка | Остановка на жёлтой сетке | 12.13 ч.1 |
| Ремень безопасности | Непристёгнутый ремень | 12.6 |
| Телефон в руках | Использование телефона за рулём | 12.36.1 |

---

## SoC: Rockchip RV1126B

| Параметр | Значение |
|----------|---------|
| CPU | 4× Cortex-A53 @ 1.6 GHz |
| NPU | **3 TOPS INT8** (RKNPU2) |
| ISP | 12MP AI-ISP, 2× MIPI CSI-2 |
| Video encode | H.265 4K@45fps, dual-stream |
| RAM | 512 MB / 1 GB LPDDR4 |
| SDK | RKNN-Toolkit2 + librknnrt |
| YOLOv8n на NPU | **~15 мс** (66 fps) |
| YOLOv5s на NPU | ~31 мс (32 fps) |

```

├── hardware/      BOM, схема подключения, даташиты

├── models/        инструкция + скрипты конвертации
├── training/      обучение и дообучение моделей
└── server/        FastAPI + PostgreSQL + MQTT брокер
```
