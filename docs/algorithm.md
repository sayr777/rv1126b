# Алгоритм работы конвейера

## Порядок обработки

```
┌─────────────────────────────────────────────────────────────────────┐
│ 1. Детекция ТС      YOLOv8n → список bbox                          │
│ 2. Распознавание номера  plate_det + LPRNet → текст номера         │
│ 3. Построение трека      ByteTrack → persistent track_id + plate   │
│ 4. Вафельная зона        Zone check → ViolationDetector             │
│ 5. Ремень + телефон      cabin cam, привязка к track_id            │
└─────────────────────────────────────────────────────────────────────┘
```

Логика такая: сначала **идентифицируем** ТС (номер + трек), потом **фиксируем** нарушения.
Событие содержит номер только если он считан до момента нарушения.

---

## Модели и время инференса (NPU INT8, RV1126B)

| Шаг | Задача                    | Модель          | Вход      | Время NPU |
|-----|---------------------------|-----------------|-----------|-----------|
| 1   | Детекция автомобилей      | YOLOv8n         | 640×640   | ~15 мс    |
| 2а  | Детекция номерного знака  | YOLOv8n (1 cls) | 320×192   | ~8 мс     |
| 2б  | OCR номера (кириллица)    | LPRNet          | 94×24     | ~4 мс     |
| 3   | Трекер                    | ByteTrack (CPU) | —         | ~1 мс     |
| 4   | Зона нарушения            | Zone (CPU)      | —         | < 1 мс    |
| 5а  | Ремень безопасности       | MobileNetV2     | 224×224   | ~3 мс     |
| 5б  | Телефон в руках           | YOLOv8n         | 640×640   | ~15 мс    |

## Поток 1 — фронтальная камера (25 fps, ~40 мс/кадр)

### Шаг 1. Детекция ТС

```
V4L2 grab → 1920×1080 BGR
→ resize 640×640
→ YOLOv8n NPU (~15 мс)
→ NMS (IoU=0.45, conf=0.45)
→ фильтр классов: car(2), bus(5), truck(7)
→ bbox_list[]
```

### Шаг 2. Распознавание номерного знака

Выполняется для каждого bbox из шага 1 (каждые 5 кадров или при новом треке):

```
для каждого bbox авто:
  a. crop авто + resize 320×192
  b. plate_det (YOLOv8n, NPU, ~8 мс) → plate_bbox
  c. crop номера + resize 94×24
  d. LPRNet (NPU, ~4 мс) → CTC decode → "А123БВ77" + conf
  e. если conf ≥ 0.70 → сохранить plate_text для данного bbox
```

### Шаг 3. Построение трека

```
ByteTrack.update(bbox_list) → Track[] { id, box, hits, plate }

Привязка номера к треку:
  если для bbox считан plate_text → track.plate = plate_text
  (номер обновляется при каждом успешном считывании)

Трек считается подтверждённым (confirmed) при hits ≥ 3
Только подтверждённые треки используются в шаге 4 и 5
```

### Шаг 4. Вафельная разметка

```
для каждого confirmed трека:
  zone.contains_center(track.box)?
    ДА:  enter_time записан?
           НЕТ → enter_time = now()
           ДА  → dwell = now() - enter_time
                 dwell > 3.0 с AND не срабатывал ранее
                   → ViolationEvent {
                       type: WAFFLE_VIOLATION,
                       plate: track.plate,   ← уже известен из шага 2-3
                       track_id: track.id,
                       dwell_sec: dwell
                     }
    НЕТ: сбросить enter_time
```

## Поток 2 — кабинная камера (25 fps)

Запускается **после** того, как главный поток получил confirmed трек с номером.
Результаты кабинного потока привязываются к `track_id` из фронтального потока.

### Шаг 5. Ремень и телефон

```
V4L2 grab → 1280×720 BGR

Шаг 5а — РЕМЕНЬ:
  crop ROI водителя (левая половина кадра, y: 10–90 %)
  → resize 224×224
  → MobileNetV2 (NPU, ~3 мс)
  → {belt_on / belt_off, conf}
  если belt_off AND conf ≥ 0.75:
    → SeatbeltEvent {
        type: NO_SEATBELT,
        track_id: active_track_id,   ← из фронтального потока
        plate: track.plate,
        conf: conf
      }

Шаг 5б — ТЕЛЕФОН:
  полный ROI водителя (левая половина кадра)
  → resize 640×640
  → YOLOv8n (NPU, ~15 мс), класс 67 = cell phone
  если bbox conf ≥ 0.50:
    → PhoneEvent {
        type: PHONE_IN_HAND,
        track_id: active_track_id,
        plate: track.plate,
        conf: conf
      }
```

**Привязка к треку:** главный поток публикует `active_track_id` через shared atomic.
Кабинный поток читает его без блокировки. Если трека нет (нет авто в зоне) —
события ремня/телефона не публикуются.

## Таймлайн одного кадра (фронтальный поток)

```
t=0     t=5     t=20    t=21    t=22    t=34    t=40
│───────│───────│───────│───────│───────│───────│
│ V4L2  │ Det.  │ LPR   │ Track │ Zone  │ (idle)│
│ grab  │ YOLOv8│ plate │ Byte  │ check │       │
│ ~5мс  │ ~15мс │ ~12мс │ ~1мс  │ ~1мс  │       │
         (NPU)   (NPU)   (CPU)   (CPU)
                  ↑ каждые 5 кадров

Кабинный поток (независимый тред):
t=0     t=3     t=18
│───────│───────│
│ V4L2  │ Belt  │ Phone │
│ grab  │ MBv2  │ YOLO  │
│ ~5мс  │ ~3мс  │ ~15мс │
          (NPU)   (NPU)
```

## Событийная модель

Все события содержат `plate` если он был считан до момента нарушения:

```
TrafficEvent {
  type:       PLATE_READ | WAFFLE_VIOLATION | NO_SEATBELT | PHONE_IN_HAND
  plate:      "А123БВ77"    (пусто — если номер ещё не считан)
  track_id:   42             (единый ID из ByteTrack для обоих потоков)
  zone:       "waffle_main"  (только для WAFFLE_VIOLATION)
  dwell_sec:  4.2            (только для WAFFLE_VIOLATION)
  conf:       0.91
  timestamp:  "2026-09-03T10:15:33Z"
  cam_id:     "cam01"
  jpeg_path:  "/snapshots/20260903_101533_42.jpg"
}
```

## Фильтрация ложных срабатываний

| Ситуация                             | Метод фильтрации                             |
|--------------------------------------|----------------------------------------------|
| Авто быстро проезжает через зону     | dwell < 3 с → не нарушение                  |
| Пешеход в зоне                       | Фильтр классов YOLOv8n (только авто)        |
| Авто на зелёный свет                 | UART-фаза светофора (опционально)            |
| Низкая уверенность OCR               | conf < 0.70 → номер не публикуется          |
| Неподтверждённый трек                | hits < 3 → игнорируется в шагах 4 и 5      |
| Ремень пассажира вместо водителя     | ROI ограничен зоной водителя (левая треть)  |
| Телефон за окном или на пассажирском | ROI ограничен зоной рук водителя            |
